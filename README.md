# Excel Sales Report Automation

## Project Overview

This project automates the creation of an Excel sales report using Python and the `openpyxl` library. It processes sales data, calculates summary statistics, and formats the report for professional presentation.

## Features

- Read and process Excel sales data
- Calculate total sales for each record
- Generate Total Revenue and Average Sales
- Identify Highest Sale and Lowest Sale
- Apply professional fonts and formatting
- Merge cells for the report title
- Adjust column widths automatically
- Add filters and freeze panes
- Validate empty and negative sales values
- Handle missing files and loading errors

## Technologies Used

- Python 3
- openpyxl
- Visual Studio Code
- Git and GitHub

## Requirements

Install Python 3 and the required library:

```bash
pip install openpyxl
```

## How to Run

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Activate your virtual environment, if applicable.
4. Ensure the input Excel file is available.
5. Run the Python script:

```bash
python excel_report.py
```
